# Upstream provenance

Pocket Buddy Plus is derived from **OpenPets**, originally developed by Boring
Dystopia Development and the OpenPets contributors.

- Upstream repository: https://github.com/alvinunreal/openpets
- Upstream project site: https://openpets.dev
- License: MIT
- Fork baseline: `d5af8e9cdd5f24b8edde75186d33d230961aac36`

The upstream `LICENSE` file and copyright notices must remain in distributions
and source releases. Prismtek-specific branding and features do not remove or
replace upstream attribution.

## Sync policy

Keep an `upstream` Git remote pointing to `alvinunreal/openpets`. Pull upstream
security, packaging, plugin-platform, IPC, and cross-platform window fixes into
small synchronization branches. Resolve conflicts without deleting Prismtek's
Buddy systems or weakening upstream security boundaries.
