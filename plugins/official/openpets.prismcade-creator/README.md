# Prismcade Creator plugin

An official PocketBuddy+ SDK v3 panel plugin for the manifest-first Prismcade Creator workflow.

The panel creates:

- `prismcade-game-manifest-v1`
- `prismcade-character-recipe-v1`

It includes the primary Prismcade templates and system selections without copying purchased game assets into PocketBuddy+.
