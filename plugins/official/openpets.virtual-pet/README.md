# Buddy Brain

This package keeps the stable id `openpets.virtual-pet` while becoming the single Buddy Brain plugin for Pocket Buddy+.

It owns lifecycle, progression, personality, drives, relationship, training, memory, tasks, inventory, customization, care commands, the pinned HUD, and the sandboxed Brain panel.

See `docs/buddy-brain-unified-plugin.md` and `MIGRATION.md` for state ownership and migration details.
