Account

Your password is sent only to Supabase Auth for this request and is never stored by Pocket Buddy+. The returned access and rotating refresh tokens are encrypted by the host secret store.

What gets synced

Buddy Cloud backs up the host-owned Buddy profile and gives the plugin durable memory, recall, missions, and append-only operation receipts. Other local files and plugin-private data stay local unless a feature explicitly opts in.
